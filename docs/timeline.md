# Timeline — Java Through the Ages

Linha do tempo dos marcos da plataforma Java e a posicao de cada modulo.

---

## 1991–1995 — Origem

| Ano | Marco |
|-----|-------|
| 1991 | Projeto "Oak" inicia na Sun Microsystems por James Gosling |
| 1995 | Java 1.0 anunciado na SunWorld; "Write Once, Run Anywhere" |
| 1995 | Netscape Navigator 2.0 suporta Applets — Java no browser |

## 1995–1997 — JDK 1.0/1.1: Applets e objetos distribuidos

| Ano | Marco |
|-----|-------|
| 1996 | JDK 1.0 — AWT, Applets, I/O basico |
| 1997 | JDK 1.1 — inner classes, RMI, JDBC 1.0, serializacao |
| 1997 | rmiregistry + rmic possibilitam objetos distribuidos |

> 01-applet-awt-browser-era representa este periodo

## 1998–2000 — Java 2: Desktop corporativo

| Ano | Marco |
|-----|-------|
| 1998 | Java 2 (JDK 1.2) — Swing, Collections Framework, JIT |
| 1999 | J2EE 1.2 — Servlets 2.2, JSP 1.1, EJB 1.1, JNDI |
| 1999 | Java dividido em J2SE, J2EE, J2ME |
| 2000 | JDK 1.3 — JNDI embutido, Java Sound |

> 02-swing-desktop-backoffice representa este periodo

## 1997–2000 — RMI: a era dos objetos distribuidos

RMI, lancado em 1997, foi a aposta da Sun para computacao distribuida antes de REST e SOAP dominarem.

> 03-rmi-branch-office-distributed-system representa este periodo

## 1999–2003 — J2EE e o Java web

| Ano | Marco |
|-----|-------|
| 1999 | Tomcat lancado pela Apache |
| 2001 | J2EE 1.3 — Servlets 2.3, JSP 1.2, EJB 2.0 |
| 2002 | JDK 1.4 — NIO, logging, assert |
| 2003 | Spring Framework 1.0 por Rod Johnson |

> 04-servlet-jsp-jdbc-intranet representa este periodo

## 2001–2005 — EJB e o enterprise Java

| Ano | Marco |
|-----|-------|
| 2001 | EJB 2.0 — beans entity, CMP, mensagem assincrona |
| 2003 | Inicio do declinio do EJB 2.x — Spring ganha adocao |
| 2006 | EJB 3.0 simplifica drasticamente o modelo |

> 05-ejb-enterprise-transaction-era representa este periodo (com documentacao sobre a complexidade)

## 2003–2008 — Java ME e dispositivos moveis

| Ano | Marco |
|-----|-------|
| 2003 | MIDP 2.0 consolidado |
| 2005 | 1 bilhao de dispositivos com Java ME |
| 2007 | iPhone lancado — sem suporte a Java |
| 2008 | Android lancado — Dalvik, nao CLDC |

> 06-javame-field-service-mobile representa este periodo

## 2004–2008 — Spring e a reacao ao J2EE

| Ano | Marco |
|-----|-------|
| 2004 | Spring 1.0 — IoC, DI, AOP |
| 2005 | Spring 2.0 — beans XML namespaces, JdbcTemplate |
| 2006 | Java EE 5 — EJB 3.0, JPA |
| 2007 | Spring 2.5 — anotacoes, `@Autowired` |

> 07-spring-xml-service-layer representa este periodo

## 2004–2006 — Java 5: a linguagem amadurece

| Ano | Marco |
|-----|-------|
| 2004 | JDK 5 (Tiger) — generics, enums, annotations, for-each, autoboxing, varargs |
| 2004 | java.util.concurrent — ExecutorService, Locks, ConcurrentHashMap |

> 08-java5-generics-annotations-concurrency representa este periodo

## 2008–2012 — REST e JSON

| Ano | Marco |
|-----|-------|
| 2008 | Spring MVC 3.0 com suporte a REST |
| 2009 | Oracle adquire Sun |
| 2011 | JDK 7 — diamond, try-with-resources, NIO.2 |

> 09-spring-mvc-rest-json representa este periodo

## 2014–2017 — Spring Boot e microservicos

| Ano | Marco |
|-----|-------|
| 2014 | Spring Boot 1.0 — autoconfiguration, embedded server |
| 2014 | Java 8 — lambdas, streams, Optional |
| 2017 | Java 9 — modules, JShell |

> 10-spring-boot-microservice representa este periodo

## 2018–2021 — Cloud Native

| Ano | Marco |
|-----|-------|
| 2018 | Java 11 (LTS) — HTTP Client, Applet removido |
| 2018 | Spring Boot 2.x — reativo, metrics, Micrometer |
| 2019 | Spring Cloud, Kubernetes se torna padrao |
| 2021 | Java 17 (LTS) — sealed classes, records, pattern matching |

> 11-cloud-native-observability-era representa este periodo

## 2021+ — Java moderno

| Ano | Marco |
|-----|-------|
| 2021 | Java 17 LTS — records, sealed classes, pattern matching for instanceof |
| 2023 | Java 21 LTS — virtual threads (Project Loom), sequenced collections |
| 2024 | Java 22 — unnamed variables, stream gatherers |

> 12-modern-java-language-evolution representa este periodo
